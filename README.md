# QUIZZ - Android Quiz Application

Ứng dụng quiz trên Android với giao diện đẹp, lưu trữ offline.

## Tính năng chính

- ✅ Đăng nhập / Đăng ký
- ✅ Danh sách bài test
- ✅ Làm bài test trắc nghiệm
- ✅ Xem kết quả ngay
- ✅ Lịch sử bài test
- ✅ Lưu trữ offline (SQLite)

## Cách sử dụng

1. Clone repo: `git clone https://github.com/usadmsm-lab/QUIZZ.git`
2. Mở Android Studio
3. File → Open → Chọn folder QUIZZ
4. Chờ Gradle sync xong
5. Run app

## Công nghệ sử dụng

- Java
- Android SDK
- SQLite
- Material Design

## Màn hình ứng dụng

1. **Splash Screen** - Logo khởi động
2. **Login** - Đăng nhập
3. **Test List** - Danh sách bài test
4. **Quiz** - Làm bài test
5. **Result** - Xem kết quả
6. **History** - Lịch sử bài test
